## 0. 怎么用这份文档

1. **例会逐卡过**：组员当场自报人日，P1 汇总后定燃尽基线。**本文档不预设总人日**——Alpha 的教训是没摸底就定 37 条口径，结果调了三次。
2. **一卡一人主责**：协同人只做对接，**不并行改同一文件**（老师 11-12 答复：同一时间段不要动同一模块）。
3. **验收标准直接抄进用例表**：P7 不另立标准，卡里写什么就测什么。
4. **降级预案写在卡里**：到期做不完按卡内预案执行，不上会重议。
5. 「不做」是防越界红线，做了等于把 RC 的活提前偷做。

### 容量口径（为什么只有 20 条）

```
Alpha 实测 1.85 条/天 × 28 天 = 52 条「Alpha 尺寸」
Beta 单条平均约 2 倍重量（横切 DB / 算法 / 跨端）→ ÷2 ≈ 26 条
```

## 3. 需求卡

### A 组 · 出口必达①：双栏阅读流

---

#### B01 · 双栏列序重排算法

- **用户故事**
  作为读者 **R**，我希望双栏论文的正文按「左栏读完 → 右栏」的顺序被抽取，以便我提问时模型拿到的是连贯段落，而不是左右栏交错的碎句。
- **主责 / 协同**：P5 / —
- **尺寸**：L　**依赖**：B13（契约加 `reading_order`）　**周次**：W1
- **输入（前置）**：现有 `_is_double_column()` 已能判定页级 / 文档级双栏，但**只判定不排序**；抽取仍靠 `get_text("blocks", sort=True)` 的默认顺序。
- **验收标准**
  1. 3 篇双栏论文（CVPR / NeurIPS 样式）重排后，人工抽 5 段：段落连贯、**无跨栏拼接**
  2. 单栏论文结果与现状**逐字节一致**：`check_chunker.py` 基线哈希不破
  3. 每个 chunk 新增 `reading_order`（页内整数，0 起），落库同名列，契约同步
  4. `bbox_mode` 按契约 1.3.1 的**精度**口径标：框住目标段落且不跨栏才可标 `precise`，只是多块并集 / 跨栏则标 `block`，无边线信息标 `null`。本卡只做列序重排、不改框精度，因此**重排后若仍给不出栏内段落框，如实标 `block` 即可**，不因「双栏」就一律标 `block`
- **技术要点**：`ai-service/app/services/chunker.py`。新增「按 x=0.5 中线聚栏 → `(column, y0, x0)` 排序 → 恒定顺序产出」。切片规则（`TARGET_MAX=700`、`OVERLAP=100`、长段硬切）**一行都不改**。
- **不做**：不改 PyMuPDF 抽取逻辑、不改重叠逻辑、不做三栏 / 异形版面排序。
- **降级预案**：三栏及异形版面直接走原顺序，标 `layout=unknown`，在 B19 里如实写明。

#### B02 · 双栏滚动与引用定位

- **用户故事**
  作为读者 **R**，我希望滚动时进度不乱跳、点引用能直接落到那段话上，以便我在双栏论文里不用自己找位置。
- **主责 / 协同**：P2 / P5（只提供数据）　**尺寸**：L　**依赖**：B01　**周次**：W2
- **现状**：① 「当前页」按视口上部 30% 判定，双栏时左右两栏高度重叠，页码/进度来回跳；② 点引用滚到页面顶部，那段话常在另一栏中部。
- **验收标准**
  1. 双栏论文连续滚动：页码/进度不再来回跳
  2. 点引用后页面停在**那段话附近**（上下不超过半屏），不是页顶
  3. 缩放 50% / 200% 后定位仍准
  4. 单栏论文行为与 Alpha **完全一致**（回归项）
- **技术要点**：`frontend/src/views/ReaderView.vue`。当前栏判据用「阅读顺序里最后可见的块」，不用页；引用跳转改块级 y 定位（`bboxY0 × 页高 − 40px`）；缩放沿用 `captureAnchor` / `restoreAnchor`。**P2 与 P5 不同时改同一文件**。
- **不做**：**不做把双栏页面重排成单栏流**（PDF 是排版文件，重排等于重做版面引擎）；不做自由拖动排版、双页并排、夜间模式。
- **降级预案**：当前栏判定做不顺，退成「只做引用块级定位 + 保持按页判定」，并在 B19 写明。

#### B03 · 引用框列内精确化

- **用户故事**
  作为读者 **R**，我点引用时希望框住的是「那一段」，而不是横跨两栏的大块。
- **主责 / 协同**：P2 / P5　**尺寸**：M　**依赖**：B01　**周次**：W2
- **现状**：Alpha 双栏一律标 `block`（65/65），框是 chunk 内多块并集，跨栏。
- **验收标准**
  1. 双栏论文 10 题：`bboxMode=precise` 命中 **≥7**，其余允许 `block`
  2. 框**不跨栏**（x0 / x1 落在同一栏区间）
  3. 旋转页 90° / 180° / 270° 仍对齐（沿用 F6-08 样本）
  4. 三态 `precise`/`block`/`null` 前端样式不变（实线 / 虚线 / 只闪页）
- **不做**：不做逐句 / 逐字级定位；不承诺与 PDF 文字层逐字重合。

#### B05 · `users` 表 + `user_id` 迁移

- **用户故事**
  作为维护者 **D**，我希望先把账号表与归属列一次迁好，以便后面所有多用户工作不用二次改表。
- **主责 / 协同**：P6 / —　**尺寸**：M　**依赖**：B13　**周次**：W1（**硬卡点**）
- **现状**：`papers.user_id` 只有 `NOT NULL DEFAULT 1`，**没有 `users` 表**、无外键。
- **验收标准**
  1. `users` 表：`id / username(唯一) / password_hash / created_at`
  2. `papers.user_id` 加外键 → `users(id)`；存量 papers 全部归 `user_id=1`（legacy 账号）
  3. 迁移脚本**幂等**，重复执行不报错
  4. **不删任何卷**（`pgdata` / `uploads` / `hf-cache` 全保留）
  5. `docs/契约/03-数据库表结构.sql` 升 **1.1.0-frozen**，头部 changelog 写明升级理由
- **不做**：不动 `chunks` / `annotation` / `reading_session` 结构；不重建数据库。
- **降级预案**：无。**迁移是 W1 硬卡点，逾期即上报，B07/B08/B09 顺延并上会说明**。

#### B06 · 注册 / 登录 + JWT

- **用户故事**
  作为多用户读者 **U**，我希望用自己的账号登录，以便我的文献和提问记录归属到我自己。
- **主责 / 协同**：P4 / —　**尺寸**：L　**依赖**：B05　**周次**：W1–W2
- **验收标准**
  1. `POST /api/auth/register`、`POST /api/auth/login`，响应走统一 `ApiResponse`（`code=0`）
  2. 密码 **bcrypt** 存储：不落明文、**不写日志**
  3. 错误码：密码错 → `4001`；账号不存在 → **同一错误码**（不泄露存在性）；token 过期 → `4002`（码值在 B13 契约里定死）
  4. token 走 `Authorization: Bearer`，有效期写进契约
  5. 伪造 / 篡改签名 → 401
- **技术要点**：`backend/src/main/java/com/papermind/backend/` 新增 `AuthController` + `JwtFilter`；错误码进 `common/ErrorCode.java`。
- **不做**：不做找回密码、短信验证码、第三方登录、角色 / 权限分级。
- **降级预案**：JWT 联调卡住先退成 **服务端 Session（Redis）**，接口签名不变，B19 记录偏离。

#### B07 · 全链路 `user_id` 过滤

- **用户故事**
  作为多用户读者 **U**，我希望只能看到、只能问我自己导入的文献，以便数据不串。
- **主责 / 协同**：P4 / —　**尺寸**：M　**依赖**：B05 B06　**周次**：W2
- **验收标准**
  1. **至少 6 处**按 token 取 `user_id` 过滤：文献列表、文献详情、删除、问答、划词 explain、检索导入
  2. 访问他人 `paper_id` → `403` 或 `2001`（**二选一，在 B13 契约写死**，不允许两种并存）
  3. 越权响应**不返回他人任何数据字段**（连标题都不许带）
  4. 删除他人文献：404 / 403 口径同上，且不得真删
- **不做**：不做共享库、团队空间、文献转赠。

#### B08 · 登录页 + 路由守卫

- **用户故事**
  作为多用户读者 **U**，我希望没登录时被引导去登录页，登录完回到我原来要看的那篇。
- **主责 / 协同**：P3 / —　**尺寸**：M　**依赖**：B06　**周次**：W2

#### B10 · 开放式概括提问召回

- **用户故事**
  作为读者 **R**，我问「这篇文献讲了什么」时希望拿到概括，而不是被回一句「本文未涉及该内容」。
- **主责 / 协同**：P5 / —　**尺寸**：M　**周次**：W2　**依赖**：—
- **根因（已定位）**：`ai-service/app/services/RAG.py` 三处叠加误拒——`top_k=3`、`QA_MIN_SIMILARITY=0.35`、prompt「只是字面相关也算未涉及」。
- **验收标准**
  1. 新增 **5 道**开放式题（讲了什么 / 解决什么问题 / 贡献是什么 / 用的什么数据 / 结论是否可靠）**命中 ≥4/5**
  2. Alpha 原 10 题**不得回退**（仍 ≥9/10）
  3. 未涉及题仍 **100% 拒答**（不许为了召回把编造放进来）
  4. `tokenUsage` 与 `elapsedMs` 仍按契约返回；耗时仍在 25 秒预算内
- **技术要点**：概览类问题识别 → 放宽 `top_k` 到 8 并取首末段 + 摘要段，**不得取消未涉及判定**。
- **不做**：不做多轮对话记忆、不换模型、不改 embedding 模型。
- **降级预案**：识别不准就退成「概览类固定 `top_k=8` + 排序去重」，不引入新依赖。

#### B11 · 引用片段语义质量

- **用户故事**
  作为读者 **R**，我希望引用片段是完整句子，而不是从词中间切开的半句。
- **主责 / 协同**：P5 / P2　**尺寸**：M　**依赖**：B01　**周次**：W3
- **现状**：Alpha 已记录问题——跨段、混小标题 / 表格、公式丢上下标、词中截断；D17 决定留后续轮次。
- **验收标准**
  1. 抽 10 条引用：**词中截断 0 条**
  2. 标题 / 表格 / 公式碎片**不作为引用首句**
  3. 每条 snippet ≤200 字，且以句末或段末收尾
  4. 引用页码命中率不下降（仍 ≥9/10）
- **不做**：不做逐句对齐、不动 chunk 大小上限（另立优化项）。

#### B14 · F5-b 多源聚合去重

- **用户故事**
  作为读者 **R**，我希望一次搜索就拿到 arXiv 与 OpenAlex 合并去重后的结果，以便不用在两个源之间来回切。
- **主责 / 协同**：P4 / —　**尺寸**：M　**依赖**：B13　**周次**：W3
- **现状**：`SearchController` 是**单源二选一**（`source=arxiv|openalex`），缓存 key = 来源 + 关键词哈希 + 分页，24 小时。
- **验收标准**
