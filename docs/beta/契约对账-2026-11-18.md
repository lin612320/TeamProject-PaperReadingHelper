## 二、逐接口明细

### 1. `GET /api/papers`（文献列表）

- **契约 `Paper`**：`id / title / filename / pageCount / source / doi / arxivId / externalUrl / createdAt`
- **实测 item**：`id / title / filename / pageCount / parseStatus / source / createdAt`
- **偏差**：
  - 🔴 **缺** `doi` / `arxivId` / `externalUrl`
  - 🔴 **多** `parseStatus`（契约 `Paper` 未定义，只在 `PaperDetail` 有）
- **判断**：契约声明过头（列表页确实不需要三个来源字段），应改契约而不是改实现
- **处置**：BUG-020

### 2. `GET /api/papers/{id}`（文献详情）

- **契约 `PaperDetail`** = `Paper` + `parseStatus` + `chunkCount`
- **实测**：`id / title / filename / pageCount / chunkCount / parseStatus / parseError / source / doi / arxivId / externalUrl / fileSize / createdAt`
- **偏差**：🔴 **多** `fileSize`、`parseError`（契约未定义）
- **判断**：实现比契约更全，契约漏写；`parseError` 对前端展示失败原因是必需的
- **处置**：BUG-020（与上条一并改契约 1.3.1）

### 3. `POST /api/qa/ask`（问答）

- **契约 `AskResult`**：`answer / citations / elapsedMs / model`
- **实测**：✅ 四字段齐全，答案含引用页码
- **契约 `Citation`**（9 字段）：`page / snippet / chunkId / readingOrder / bboxX0~Y1 / bboxMode`
- **实测 `Citation`**（8 字段）：`page / snippet / chunkId / bboxX0~Y1 / bboxMode`
- **偏差**：🔴 **缺 `readingOrder`**（1.3.0 新冻结项，实现待 `#86`）
- **错误码对照**：

| 场景 | 契约 | 实测 | 结论 |
|---|---|---|---|
| 空问题 | 2003 / HTTP 422 | 2003 / HTTP 422 | ✅ |
| 论文不存在 | 2001 / HTTP 404 | 2001 / HTTP 404 | ✅ |
| 未解析完成 | 2002 / HTTP 409 | 无样本可测 | ⏸ |

- **处置**：BUG-022

### 4. `POST /api/explain`（划词翻译）

- **契约 `ExplainResult`**：`translation / explanation / mode / truncated`
- **实测**：✅ 四字段齐全，`mode=term` 返回「变换器」+ 白话解释

### 5. `GET /api/search`（关键词检索）

- **契约 `PaperMetaList`**：`total / items / degraded / cached`
- **实测**：✅ 四字段齐全
- **item 字段**：实测 9 个（`abstract / arxivId / authors / doi / landingUrl / pdfUrl / source / title / year`）= 契约 `PaperMeta` **完全一致** ✅
- **错误码**：空关键词 → 1001 / HTTP 400 ✅
- **⚠️ 非字段问题**：实测 arXiv 单次 **9.19 秒**，而契约写的超时是 10 秒（代码拆两次各 5 秒）→ 必然降级。已改 `APP_SEARCH_TIMEOUT_SECONDS=30`，**契约待升 1.3.1**（BUG-021）

### 6. `POST /api/auth/*`（1.3.0 四接口）

- 实测 `GET /api/auth/me` → **HTTP 404 + `code=1001`**
- 说明：auth 属 Beta W2–W3 排期（`#71`–`#75`），未实装属预期，**不算缺陷**
- ⚠️ **实现时注意**：契约规定未带令牌应回 **401 / 6002**，不要落在 404/1001

### 7. 上传接口的错误码

| 场景 | 契约 | 实测 | 结论 |
|---|---|---|---|
| 空文件 | 契约只写「400 非 PDF 或文件为空」，未指定码 | **1001** | ⚠️ 契约未明确，观察项 |
| 后缀非 .pdf | 1002 | 未单独实测 | ⏸ |
| 真 PDF | 200 | 200（`id=51` 实测后已删除） | ✅ |

## 四、需要契约 1.3.1 解决的问题（三条，合并成一次升级）

1. **补字段**：`Paper` 增 `parseStatus`；`PaperDetail` 增 `fileSize`、`parseError`；并明确 `doi/arxivId/externalUrl` **列表项不返回**
2. **补超时**：检索外部源 **30 秒**，单次尝试 15 秒，依据是实测 9.19 秒
3. **明确空文件错误码**：建议统一 **1002 `FILE_NOT_PDF`**（当前实现返回 1001）

> 这三条都是「契约落后于实现」，不改代码；改完升 **1.3.1-frozen**，由 P1 裁定，例会通报即可（沿用不等回执的做法）。
