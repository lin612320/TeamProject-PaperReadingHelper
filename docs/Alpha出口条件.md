## 二、Alpha 出口条件（正式判定项）

判定标准沿用「**主链不断、无 P0**」，逐条可测：

### 1. 主链六步（必须全部走通）

| 步   | 动作                         | 判定标准                           | 状态                  |
| --- | -------------------------- | ------------------------------ | ------------------- |
| ①   | `docker compose up -d` 起全栈 | 五容器 healthy，前端经 nginx（8081）可访问 | ✅ 11-09 通过          |
| ②   | 上传 PDF                     | ≤3 秒；页数、切分数与原文一致               | ✅ 0.07 秒 / 7 页 11 片 |
| ③   | 在线阅读                       | 渲染无白屏、翻页/缩放/跳页正常               | ✅ 真机通过              |
| ④   | 单篇提问                       | 返回答案 + 引用片段 + 页码；答案不编造         | ✅ 1.31 秒            |
| ⑤   | 点引用页码 → 跳原文                | 跳到对应页并定位到该段                    | ✅ 真机截图留证            |
| ⑥   | 传非 PDF                     | 明确报错（`400 / 1002`），不静默入库       | ✅ 回归修复后通过           |

### 2. 答案质量（可量化）

- 抽 **3 篇论文 / 10 题**，覆盖方法、结论、细节三类难度
- **引用页码命中 ≥ 7/10**
- 论文未涉及的问题必须返回「本文未涉及该内容」+ 空引用，**要求 100%**

实测（`#20`）：**命中 9/10（90%）**，未涉及题 **3/3（100%）**。判定口径见 `docs/测试/命中率判定口径.md`。

### 3. 延展段新增三项（本轮已提前实现，纳入出口）

| 功能              | 判定标准                                                            | 状态                                                        |
| --------------- | --------------------------------------------------------------- | --------------------------------------------------------- |
| **检索与导入**       | 关键词搜到 ≥5 条、一键导入后可直接提问；非 OA 只给链接；外部不可达时降级不 500                   | ✅ 11-13 集成走查通过（检索→导入→提问）                                  |
| **引用 bbox 高亮**  | 点引用 → 跳页 + 画框；`bboxMode` 为 `precise`/`block`/`null` 三态处理；缩放后仍对齐 | ✅ 11-13 集成走查通过（跳页+画框+缩放对齐）                                |
| **划词翻译 / 术语解释** | 选中文本 → 浮层出中文；`truncated` 有提示；`mode=term` 首句为白话定义                | ✅ 11-13 集成走查通过（译文浮层 + 截断提示，`/api/explain` 于 `8da2ab6` 恢复） |

> ⚠️ 三项的统一判定是「**在真实环境跑通一次**」，代码提交不算通过。

## 三、顺延到 Beta 的项（明确记录，不是"没做完"）

| 项                    | 顺延理由                                        |
| -------------------- | ------------------------------------------- |
| **双栏阅读流排序**          | 需要版面分析算法，本轮未能做到可演示质量；属 Beta 主菜              |
| **登录 / 多用户隔离**       | 需 JWT 与 `user_id` 迁移，本轮优先保主链                |
| **批注 / 书签**          | `annotation` 空表已建，功能留 RC                    |
| **引用展示美观度优化**        | 视觉瑕疵（词中截断、引用小标题/表格），不影响主链，D17 会上决定留 Beta/RC |
| **跨文献对比、阅读看板**       | RC 范畴                                       |
| **压测、一键部署包、演示视频**    | RC 范畴                                       |
| **非 OA 多源聚合去重、检索历史** | Beta/RC 递进                                  |

## 五、判定结论

**Alpha 阶段出口条件成立的前提是三条同时满足：**

1. 主链六步在容器环境（8081）全部走通，无 P0
2. 延展段三项新功能（检索导入、引用 bbox 高亮、划词翻译）**均已跑通**并可在演示脚本中呈现
3. 缺陷清单无 P0、S1 全部有明确处置；契约与用例表状态与实现一致

**降级预案**：若三项新功能在 11-13 集成走查仍未跑通，则按「检索导入 + 跳页/整段框」的最小可演示组合交付，划词翻译顺延 Beta，并在 `#44` 报告中如实说明。

本轮三项均已跑通，**降级预案未触发**。
