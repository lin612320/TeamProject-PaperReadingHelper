# 数据流图（DFD）

> 本目录存放「论文阅读助手」的分层数据流图成品图。
> 绘制规范与自查清单见 [`../数据流图提示词.md`](../数据流图提示词.md)。
> 参与评审：全组 · 维护：P1 林子航

## 图例

| 要素 | 图形 | 编号 |
|---|---|---|
| 外部实体 | 矩形 | E1 读者 · E2 本地文件系统 · E3 大模型服务 |
| 加工（处理） | 圆形 | P0 / P1–P5 / P2.x / P4.x |
| 数据存储 | 圆柱 | D1 论文库 · D2 段落向量库 · D3 运行日志库 |
| 数据流 | 带箭头连线 + 名称 | 如「PDF 文件」「答案与引用」 |
