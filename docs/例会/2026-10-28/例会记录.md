## 三、会上定的规则（4 条）

| # | 规则 | 说明 |
|---|---|---|
| 1 | **文档统一交 markdown（.md）** | GitHub 无法直接查看 `.doc`，md 结构清晰、能在线看、能 diff |
| 2 | **master 定位** | 用于代码审核与本地调试，**不是正式发布分支** |
| 3 | **release 定位** | 最终交付分支，由组长在验收节点合并 |
| 4 | **PR 可自行合并** | 成员在本地跑通验收标准、且满足 Issue 要求后，**可自行合并 PR**，不必等组长逐个审 |
