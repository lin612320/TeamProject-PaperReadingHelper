## 二、会上定的规则（8 条）


| # | 规则                                    | 说明                                                                            |
| - | --------------------------------------- | ------------------------------------------------------------------------------- |
| 1 | **完成一个 Issue 就推**                 | 严禁攒多个一起推；燃尽图靠 Issue 开关，攒推会让曲线失真                         |
| 2 | **契约已冻结，改字段先协商**            | 浏览器↔后端、后端↔大模型、数据库字段名三份均锁在 `1.0.0-frozen`，禁止私自改动 |
