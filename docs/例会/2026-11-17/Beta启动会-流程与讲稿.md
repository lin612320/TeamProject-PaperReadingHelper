# 2 段 · Beta 功能（20:10–20:55，45 分钟）

## 2.1 主线三句话（5 分钟）

> 【看屏幕：`Beta功能说明-讲给组员.md` §一 那张「用户抱怨 → 要做什么」表】

**讲稿**

> Alpha 我们做到了「传上去、看得见、问得出、跳得准」。但真拿它读论文，用户会卡在三件事上。
>
> **第一件：双栏论文读起来乱，问它问题答得也乱。** 现在电脑是按 PDF 里的原始顺序读字，双栏时会「左一句、右一句」。我们的代码能判断这页是双栏，但**只是打了个标记，没有真的重新排队**。这就是 Beta 最硬的技术活。
>
> **第二件：我和室友用同一台电脑，我的论文跑到他列表里去了。** 数据库里 `user_id` 这一列**一直是 1**，连 `users` 表都没建。所以 Beta 要把「人」这个概念先立起来。
>
> **第三件：上次演示前数据差点没了，网一断还说'没搜到'。** 所以要能备份、能报警、能自动检查代码。
>
> 一句话：**Beta 是把「能演示的 Demo」变成「敢给别人用的产品」。**
>
> 二十张卡我分四组，现在逐组过。**每组只讲三件事**：要变成什么样、最难在哪、做不完怎么降级。细节文档里有，我不复述。

## 2.2 四组串讲（30 分钟）

### A 组 · 让论文读得顺（B01–B04）— 8 分钟，P5 与 P2 重点听

> 【看屏幕：`Beta功能说明-讲给组员.md` B01 的「现在什么样」对比图】

**讲稿**

> ```
> 现在：左上 → 右上 → 左中 → 右中 → 左下 → 右下   ❌ 横着扫
> 之后：左上 → 左中 → 左下 → 右上 → 右中 → 右下   ✅ 竖着读完换栏
> ```
>
> 读报纸的常识：先把左栏从上读到下，再换右栏。电脑不懂这个常识，得我们告诉它。
>
> **B01 是全项目最难的卡，压在 P5 身上。** 难在哪：切片规则一个字都不能改——700 字上限、100 字重叠、超长段硬切，全都保持原样，只在「喂进去之前」把顺序调对。改完必须跑 `check_chunker.py` 比基线哈希，**证明没顺手改坏单栏**。
>
> **降级线我定死了**：三栏、异形版面（图表横跨两栏那种）不做，直接走原顺序，标 `layout=unknown`，在出口条件里如实写。**不许假装做完了。**
>
> B02 渲染是 P2 的活。**这里有一条纪律**：B01 出数据在前，B02 接渲染在后，**你和 P5 不许同时改 `ReaderView.vue`**。`#41` 和 `#42` 并行就把这个文件撞了。
>
> B03 是把引用框从「横跨两栏的一大块」收成「一栏内的那一段」。Alpha 测的 65 个双栏引用**全是整块框**，这次目标是十道题里至少七道精确到栏内。
>
> B04 单独列一张回归卡，原因我上一段讲过了——**上轮就是因为只测改动不跑回归，才让一个已修的 bug 悄悄回来了。**

### B 组 · 让账号分得清（B05–B09）— 8 分钟，P6 与 P4 重点听

**讲稿**

> 这一组的地基是 **B05：建 `users` 表 + 数据迁移**，P6 的活。
>
> 现状：`papers.user_id` 全是 1，没有外键、没有用户表。Beta 要在不丢任何数据的前提下，把「用户」这个概念立起来——**以前传的论文全部归到一个 legacy 账号**。
>
> 三个要求：**幂等**（跑一次和跑三次结果一样）、**一个卷都不许删**、表结构文档升 1.1.0。
>
> ⛔ 顺便重申一条红线：**任何人不许 `docker compose down -v`。** `-v` 会把 `hf-cache`（2.2GB 向量模型）和 `uploads`（所有 PDF）一起删掉，模型没了要重新联网下，**演示环境当场报废**。
>
> ⚠️ **B05 没有降级预案。** 11 月 22 号前迁不完，我上报，B07/B08/B09 顺延。这是本轮唯一一个「只能成、不能拖」的卡。
>
> B06 是 P4 的登录：密码用 bcrypt 存（加盐单向哈希，拿到库也反推不出原密码），登录成功发一张有时限的 JWT。有一处容易做错我提醒一下——**账号不存在和密码错误要用同一个错误码**，不然别人能拿它试探「这个用户名存不存在」。
>
> B07 最容易被漏：**六处接口都要按人过滤**——列表、详情、删除、提问、划词解释、检索导入。只在列表加过滤、详情忘掉，是最常见的翻车方式，P7 会挨个试。
>
> B09 的验收方式是：开两个账号 A 和 B，交叉做九件坏事，**全部必须被拒绝**。数据隔离这件事，「我做了」和「我证明了」是两回事。

### C 组 · 补两个体验洞（B10–B12）— 5 分钟，P5 重点听

**讲稿**

> **B10 是我最想修的一个。** 你问「这篇文献讲了什么」，它回你「本文未涉及该内容」。换个问法就答得出来。Alpha 测试唯一失败的那道题就是这个。
>
> 为什么？不是模型笨，**是我们自己把门关太紧了，三道关卡叠在一起**：
>
> 1. 只找 3 段（`top_k=3`）——「讲了什么」这种问题全篇都相关，3 段装不下摘要 + 方法 + 结论
> 2. 相似度门槛 0.35——短问题的向量很飘，天然低分，直接被拒
> 3. Prompt 写的是「只是字面相关、但没给出答案，同样算未涉及」——概括题本来就没有「原文那一句」
>
> 修法的难点在**平衡**：要能答概括题，但**拒答机制不能拆**。未涉及题 100% 拒答是 Alpha 唯一一个满分指标，丢了它换召回，不划算。
>
> B11 是引用片段的问题：现在是 `snippet[:200]`，第 200 个字是什么就切在哪，会出现「前半句 + 半个单词」。引用是让人信的东西，切一半的句子读起来就像抓包截断。
>
