## 约定：

- **S0** 不过 → Alpha 不算完成；**S1** 不过 → 记问题、报告里说明；**S2** 记录即可。（S = Severity，与分工编号 P1–P7 区分）
- 状态只有：未执行 / 通过 / 不通过 / 测不了 / 不适用。

## 判定口径（组长 2026-11-09 三条硬规矩）

1. **「未执行」必须写原因**，格式固定：`未执行 —— 依赖 #41 未交付`。没有原因的空格子一律打回。
2. **「不通过」必须带 Bug 编号**（登记进 `docs/测试/BugList.md`），不许只写"不通过"三个字。
3. **S0 必须全绿**。S0 有一条红，Alpha 不算完成；S1 红了记结论；S2 允许只做记录。

**本轮 S0 清单（13 条）**：F5-01、F5-03、F5-08、F5-09、F5-10、F6-01、F6-02、F6-04、F6-06、F7-02、F8-01、F8-02、F9-01
