## 二、逐条证据

### ① 一条命令起全栈 —— 通过

```powershell
docker compose up -d
docker compose ps
# papermind-ai / papermind-backend / papermind-frontend / papermind-postgres / papermind-redis
# 四个应用容器 + 数据库全部 healthy
```

入口可达性（经前端 nginx 代理，模拟真实用户）：

```
后端 8080        → 200
AI   8000/health → {"status":"ok","embeddingModel":"bge-m3","vectorDim":1024,"dbReady":true}
前端 8081        → 200
前端 /api 代理   → 200
```

后端启动自检日志（`#23` 要求的一行）：

```
[STARTUP] port=8080 db=ok redis=ok ai-service=down(ResourceAccessException)
# AI 起来之后为 ai-service=ok
```

### ② + ②-补 上传与解析 —— 通过

```
POST /api/papers（demo-7p.pdf，1,234,254 字节，真实 7 页）
HTTP 200   0.071s   {"parseStatus":"pending"}
轮询 → 21s  {"parseStatus":"ready","pageCount":7,"chunkCount":11}
```

**页数与文件真实页数一致**（7 = 7），BUG-006「页数恒 15」确认已修复。

### ③ 渲染 / 翻页 / 缩放 —— 通过

真机 Chrome 打开 `/reader/{id}`：第 1 页完整显示、无错位白屏；翻页、跳页、缩放（50%~200%）均正常，缩放后保持阅读位置。

### ④ 提问 + 页码 —— 通过

```
POST /api/qa/ask {"paperId":13,"question":"10-30 那天站会剩余 Issue 是多少？"}
HTTP 200   1.31s
答案：「10-30 那天站会剩余 Issue 是 20/28。」   ← 与原文一致
citations：page 6 / 1 / 6，每条含 chunkId，bboxX0~Y1 均为 null（契约要求）
```

拒答验证：

```
问题：「这个实验用了多少只小白鼠？」
答案：「本文未涉及该内容」，citations: []      ← 未编造，契约要求
```

错误分支（全部实测）：

| 场景 | 响应 |
|---|---|
| 未解析就提问 | `409 / 2002` |
| 空问题 | `422 / 2003` |
| 不存在文献 | `404 / 2001` |
| AI 服务未启动 | 解析 `parseError` 写明「无法连接 AI 服务…连接被拒绝」 |

### ⑤ 点页码跳原文 —— 通过

真机截图留证：[`evidence/D11-01-citation-jump.png`](evidence/D11-01-citation-jump.png)

点引用卡「第 3 页」→ 左侧 PDF 跳至第 3 页（分页显示 `3 / 7`），页面正文正是引用片段所在段落。

## 三、本轮发现并修复的缺陷（共 8 条）

| 编号 | 现象 | 根因 | 状态 |
|---|---|---|---|
| BUG-006 | 页数恒为 15、切片恒为 128 | 解析走 mock 且默认开启 | ✅ 修复（`mock` 默认关 + 真实解析） |
| BUG-008 | 解析失败只写 `unknown error` | `getMessage()` 为空时未兜底 | ✅ 修复（连接失败/超时/5xx 分类文案） |
| BUG-004 回归 | 纯文本改名 `.pdf` 能入库 | 加后缀校验时删掉了 `isPdf()` 调用 | ✅ 修复（两段校验并存，`03ca4b8`） |
| 解析超时 | 25 秒必超时（实测需 60~180 秒） | 超时硬编码，且与问答超时混用 | ✅ 修复（可配置 180 秒，契约 1.0.1 同步） |
| 容器化-1 | AI 镜像拉 3GB CUDA 依赖，构建 9 分钟卡死 | pip 默认源装 CUDA 版 torch | ✅ 修复（CPU 版 torch，镜像 2.43GB） |
| 容器化-2 | 经 nginx 上传 1.2MB 文件返回 **413** | nginx 默认 `client_max_body_size 1m` | ✅ 修复（改 55m，并加长代理超时） |
| 容器化-3 | 解析报 `FILE_NOT_FOUND` | 上传卷只挂 backend，未挂 ai-service | ✅ 修复（`uploads:/app/uploads`） |
| API Key 未转发 | 设置页填的 Key 不生效（传假 Key 仍能答对） | `QaController` 组装请求时漏掉 `apiKey` | ⏳ 已批注 `#19`，待 P4 修复 |
