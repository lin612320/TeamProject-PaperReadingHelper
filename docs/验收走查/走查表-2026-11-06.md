
### ④ 提问 —— ✅ 再次通过

```
问题：10-30 那天站会剩余 Issue 是多少？
答案：10-30 那天站会剩余 Issue 是 20/28。   ← 与原文一致
耗时：1.31s
引用：page 6 / 1 / 6
```

### ④-补 拒答 —— ✅（沿用 11-05 结论）

问「这个实验用了多少只小白鼠？」→ 「本文未涉及该内容」+ `citations: []`。
`bboxX0/Y0/X1/Y1` 四字段均存在且为 `null`，`chunkId` 存在，`page` 从 1 起 —— 契约逐字段核过。

### ⑥ 错文件报错 —— ❌ 回归仍在（截至本地 `8b22454`）

| 输入 | 期望 | 实际 |
|---|---|---|
| 纯文本（1,900 字节，头是 `This`）改名 `fake.pdf` | 400 / `1002` | **HTTP 200，入库 `id=12`** ❌ |
| `not-a-pdf.docx`（内容是合法 PDF） | 400 / `1002` | 400 / `1002` ✅ |

原因仍是 `410ed69` 把 `isPdf()` 的调用删了（方法在 `PaperController.java:195`，全后端零调用）。

**补充证据（BUG-008 修复质量良好）**：脏文件（纯文本）解析时，失败原因被完整写进 `parseError`：

```
解析失败：AI 服务返回 400：{"code":"NOT_PDF","message":"无法解析该文件，可能不是合法 PDF"}
```

两层原因（后端 + AI 服务）都带出来了，用户和测试都能定位。
