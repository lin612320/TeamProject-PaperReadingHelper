## 四、工作中遇到的困难

**1. 术语与概念不熟，边学边做。** 跨域、接口契约、错误码、PDF 坐标、RAG 各环节，多数人是第一次接触。

**2. 实现与契约不一致（3 条）。** 上传响应泄露服务器磁盘路径、缺 `pageCount` / `createdAt`、超 50 MB 返回 `5000` 而非 `1003`。已全部记入 Bug List，按严重程度排期修复。

**3. 缺少访问日志。** 请求发出后控制台只有启动日志，看不到路径、文件名与状态码，出问题无法定位。

**4. 代码审查发现 6 条阻断（11-01 会上通报）。** 缺 `qa` 接口、`requirements.txt` 缺依赖、数据库密码硬编码、`parse.mock` 默认开、错误码 `4001` 应为 `2001`、前端无上传调用。已列入 D7 处理。

## 八、本周习得的软工原理 / 方法 / 技能

| 领域    | 技术                       | 本周用到 / 学到                                                             |
| ----- | ------------------------ | --------------------------------------------------------------------- |
| 前端    | Vue3 + Element Plus      | 三个视图、路由跳转、加载 / 失败 / 重试三态处理                                            |
| 前端    | PDF.js                   | canvas 渲染、worker 配置、按页码跳转；渲染是异步分页的                                    |
| 后端    | Spring Boot              | `JdbcTemplate` 查库、统一响应结构、全局异常处理、`@Async` 异步解析                         |
| 后端    | 文件上传                     | `multipart/form-data` + UUID 重命名；校验文件头而不只是后缀                          |
| AI    | PyMuPDF + 切片 + Embedding | blocks 抽取；500~800 字一片、重叠 100 字；`bge-m3` 输出 1024 维                     |
| 数据    | PostgreSQL + pgvector    | 4 张表、`CHECK` 锁枚举、级联删除、`vector(1024)` 列                                |
| 部署    | Docker Compose + Redis   | `healthcheck`、命名卷（改 SQL 要 `down -v` 才生效）、连接地址走环境变量                    |
| 协作与测试 | Git / PR / curl          | 分支开发，部分走 PR（如 #34），多数直接合入 master；commit 带 Issue 编号；用 `curl` 直测接口，不等前端 |
